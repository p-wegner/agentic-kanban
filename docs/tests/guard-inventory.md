## How each column is derived — and what it is NOT

- **kinds** — the always-run set is imported from `scripts/test-mine.mjs` (`scanAlwaysRunTests`,
  `ALWAYS_RUN_TESTS_DIR`), never re-implemented, so this report cannot describe a different set
  than the gate forces. Ratchets are matched by filename over the same package test trees.
- **property** — first line of the leading `/** … */` block, else the rationale after the
  `@gate:always-run` marker, else the first `describe()` title, else `MISSING`. The source is
  recorded per row: a property read off a describe title is a weaker claim than a written one.
- **introduced** — `git log --diff-filter=A --follow`, the commit that added the file.
- **last red (proxy)** — ⚠ **this repo has no gate-outcome / base-health ledger**: neither the DB
  schema nor `docs/tests/` records which suite was red on master when. The column is therefore a
  PROXY — the most recent commit whose message both names the file and reads like a fix. An empty
  cell means *no such commit was found*, which makes the row a candidate for "never red since
  introduction", not a proof of it.
- **wall** — read from `docs/tests/durations.json` (committed output of `pnpm test:durations`).
  Nothing is timed here on purpose: running the guard set to measure it is the cost this
  inventory exists to reduce. Blank = not in that file, listed under *unmeasured* below.
